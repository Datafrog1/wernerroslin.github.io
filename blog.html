August 10, 2026Personal branding

From portfolio to personal brand

A technical portfolio answers “what can you build?”. A personal brand should also answer “what do you want to be known for?” and “why should the visitor remember you?”. My site redesign started by making that difference visible.

Read note

The biggest change was not visual. It was structural: the home page now introduces a clearer value proposition, the portfolio explains project purpose and outcomes, and the thesis case connects the practical site to a wider business and marketing perspective.

August 10, 2026AI

AI as a creative partner, not an autopilot

Generative AI is excellent at producing options quickly. The harder work is deciding which option actually fits the goal, the audience and the brand.

Read note

My practical rule is simple: use AI to accelerate exploration, then validate the output. Code must be tested, claims must be verified, and generic text must be rewritten until it sounds like a real person rather than a template.

July 11, 2026AI development

My AI love–hate story

I like ideas to happen quickly. AI keeps the momentum going, but it also has a habit of adding complexity that was never requested.

Read note

The lesson has been to prompt more precisely: keep it simple, make one change at a time, and do not add features that do not support the goal. This approach makes AI-assisted development much easier to control.

July 8, 2026Design system

Design system setup

Centralising styles helped the site stay visually consistent across the home, portfolio, thesis and blog pages.

Read note

A small set of reusable design tokens — spacing, borders, text colours, card surfaces and accent gradients — made it easier to make changes without creating a slightly different visual language on every page.

July 4, 2026Web development

Building this portfolio

The site is built from core web technologies and published through GitHub Pages. The goal is to keep the setup lightweight and easy to maintain.

Read note

The project also works as a learning environment. Because the codebase is small, changes in structure, accessibility, responsiveness and content can be tested without a heavy framework getting in the way.
